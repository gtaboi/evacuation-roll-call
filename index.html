Setup needed

This copy of the app isn't connected to a database yet. The site owner needs to:

  1. Create a free project at supabase.com.
  2. Run supabase/schema.sql in the project's SQL Editor.
  3. Paste the project URL and anon key into config.js.

Full steps are in the repository's README.
